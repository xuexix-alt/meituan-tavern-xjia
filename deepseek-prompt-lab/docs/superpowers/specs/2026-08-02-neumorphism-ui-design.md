# 克制型新拟态界面设计

## 目标

在不改变提示词编辑、API 调用、历史记录、导入导出和移动端工作区行为的前提下，将工作台视觉重排为克制型 Neumorphism / Soft UI。

## 视觉方向

- 使用浅灰绿色中性底色，降低纯白页面的刺眼感。
- 工作区采用无强边框的双阴影浮起面板。
- 输入框、文本域和代码编辑器使用内凹阴影表达可编辑区域。
- 主操作保持绿色高对比度；普通操作使用浅色浮起按钮；危险操作保留低饱和红色。
- 深色原始 JSON 编辑器保留，作为代码阅读和状态对比锚点。

## 布局

- 桌面端继续使用连接、编辑、检查三栏结构。
- 编辑区消息项减少线框感，以轻微浮起层级分隔。
- 移动端继续使用连接区、编辑区、检查区三个标签，标签改为柔和浮起/按下状态。
- 不调整组件数据结构和 API 接口。

## 可用性

- 保留现有焦点轮廓、禁用态、错误态和成功态颜色。
- 阴影只承担层级表达，不替代文本对比和焦点反馈。
- 兼容 `prefers-reduced-motion`，不增加必须依赖动画的交互。
