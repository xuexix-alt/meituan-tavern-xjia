# 简易MVU触发器 Demo 使用说明

## 📌 项目简介

这是一个演示如何使用 `generate()` 函数后台调用AI生成变量更新指令，而不触发新聊天楼层的Vue前端界面项目。

## 🎯 核心功能

1. **后台AI调用**：使用 `generate()` 函数直接调用AI，不创建新楼层
2. **JSON Patch解析**：解析AI返回的JSON Patch格式变量更新指令
3. **MVU变量更新**：将更新应用到MVU变量系统
4. **实时状态显示**：显示MVU连接状态和变量变化

## 🔧 技术实现

### generate() 调用

```typescript
const result = await generate({
  user_input: systemPrompt,
  overrides: {
    char_description: '',
    char_personality: '',
    scenario: '',
    chat_history: {
      prompts: []
    }
  }
});
```

**关键点：**
- ✅ 不使用聊天历史 (`max_chat_history: 0`)
- ✅ 清空角色相关提示词，避免干扰
- ✅ 不创建新楼层（没有 `/send` 命令）

### JSON Patch解析

AI返回格式：
```yaml
<update>
<update_analysis>
分析当前需要更新的变量...
</update_analysis>
<json_patch>
[
  { "op": "replace", "path": "/demo_test_value", "value": "新值" }
]
</json_patch>
</update>
```

解析过程：
1. 提取 `<update_analysis>` 和 `<json_patch>` 部分
2. 验证JSON Patch格式
3. 逐个应用更新操作

### MVU变量更新

```typescript
// 获取当前MVU数据
const mvuData = Mvu.getMvuData({ type: 'message', message_id: 'latest' });

// 应用JSON Patch
for (const update of updates) {
  if (update.op === 'replace') {
    _.set(mvuData.stat_data, update.path.slice(1), update.value);
  }
}

// 写回MVU数据
await Mvu.replaceMvuData(mvuData, { type: 'message', message_id: 'latest' });
```

## ⚠️ 注意事项

1. **MVU框架依赖**：必须先安装并初始化MVU变量框架
2. **酒馆环境**：只能在酒馆环境中运行
3. **AI响应时间**：调用AI需要等待，根据模型性能而定
4. **错误处理**：所有操作都有try-catch错误处理
5. **变量路径**：使用JSON Pointer格式，如 `/demo_test_value`
