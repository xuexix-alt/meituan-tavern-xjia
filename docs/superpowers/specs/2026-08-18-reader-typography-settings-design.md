# APP 正文阅读排版调节器设计

## 目标

为 `src/APP` 的 `/story` 正文阅读器增加字号与行距调节器，改善正文阅读体验。当前正文排版字号偏大、行距偏松（17px / 1.82），用户需要可连续调节、可记忆的阅读排版。

本次改动仅涉及正文阅读器的排版与顶栏 UI，不改变酒馆消息持久化、生成请求、回退、历史记录或自动滚动逻辑。

## 用户体验

### 默认排版

正文默认字号与行距从当前值收紧，贴近主流阅读排版：

| 参数 | 当前值 | 新默认值 | 调节范围 | 步进 |
|------|--------|----------|---------|------|
| 字号 | 17px（窄屏 16px） | **15px** | 13–20px | 1px |
| 行距 | 1.82（窄屏 1.76） | **1.6** | 1.3–2.2 | 0.1 |

窄屏与宽屏统一由同一个变量控制，不再区分两套硬编码值。

### 入口与交互

- 正文顶栏右侧新增「Aa」按钮（`fas fa-text-height`），位于「历史」按钮左侧。
- 点击「Aa」切换弹出调节面板；点击面板外区域或再次点击按钮关闭，点击面板内部不关闭。
- 面板包含两组滑块与当前值展示：
  - **字号组**：`A−` · 滑块 · `A+`，右侧显示当前 px 值。
  - **行距组**：滑块 + 当前数值。
- 滑块 `@input` 即时生效并持久化。
- 面板提供「恢复默认」按钮，重置为 15px / 1.6。
- 调节结果作用于**整个正文阅读器**：正文段落、「你的行动」折叠区、正文历史弹层中的正文。

### 持久化

- 使用 `localStorage`，沿用 `app-theme` 先例：
  - `app-reader-font-size`：字号，如 `"15"`。
  - `app-reader-line-height`：行距，如 `"1.6"`。
- 启动时读取，无则使用默认值；调节时即时写入。

## 实现边界

### 排版变量

调整 `src/APP/app.vue`：

1. 在 `.phone-frame` 上动态绑定 `--reader-font-size` 与 `--reader-line-height`，值来自 `localStorage`（默认 15px / 1.6）。
2. 在挂载初始化时读取持久化值并应用。

调整 `src/APP/story/StoryMessageBody.vue`：

- `font-size: var(--reader-font-size, 15px)`、`line-height: var(--reader-line-height, 1.6)`。
- 删除现有 `17px / 1.82` 硬编码及窄屏 `16px / 1.76` 分支。

### 顶栏与调节面板

调整 `src/APP/story/StoryReader.vue`：

1. 顶栏 `grid-template-columns` 从 `44px minmax(0, 1fr) 44px` 改为 `44px minmax(0, 1fr) 88px`，右侧依次放置「Aa」与「历史」两个 44px 按钮。
2. 调节面板在 `StoryReader.vue` 内联实现（YAGNI，不单独建组件），以绝对定位浮层挂载于阅读器内。
3. 面板内使用 `<input type="range">`，`@input` 更新 CSS 变量与 `localStorage`。
4. 触控目标保持 44px 级，按钮提供 `aria-label`。

### 无干扰

- 不引入 `vh`/`dvh`，面板为绝对定位浮层，不改变外层高度，符合 iframe 适配约定。
- 不修改酒馆变量、不触发生成请求。

## 测试与验证

- 运行现有 story 相关单元测试，确认无回归（`storyDisplay`、`storySession` 等与排版无关，应保持通过）。
- 本地执行 `pnpm build`，确认 webpack 编译通过。
- 手动验证：进入正文 → 点击「Aa」→ 调节字号与行距即时变化 → 刷新后设置保留 → 「恢复默认」回到 15px / 1.6。
