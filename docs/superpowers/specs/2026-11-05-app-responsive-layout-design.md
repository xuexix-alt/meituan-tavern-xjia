# 美人团 APP 自适应布局

用户已同意现场检查建议，并要求电脑版填满宽度。

- APP 使用酒馆楼层内全部可用宽度，不拓宽宿主酒馆聊天设置。
- 高度读取同源宿主聊天可视区，与 visualViewport 求交；不使用 vh，不改宿主样式，不把 iframe 自身高度作为测量依据。
- 高度变化时，仅对原本可见的 APP 在渲染器同步高度后恢复滚动位置；普通滚动不自动拉回。低于 440px 的可用高度使用紧凑顶栏、导航和正文输入区，保留 44px 触控目标和底部安全区。
- 首页顺序为短品牌栏、搜索、分类、特色玩法。公告和说明默认折叠；900px 以上放侧栏。分类窄屏四列，620px 以上八列。
- 店铺列表以至少 300px 的卡片宽度自动分列；标题最多两行，套餐数量放到辅助行。
- 正文按钮改到顶栏右侧并预留空间，保留状态和路由语义。阅读正文占满壳层，内容列保持适宜行宽。
- 保留生成、取消、订单、MVU、聊天同步和主题行为，不新增依赖。
- 核对现有测试、构建与 320/390/768/1280/1920px 视口，包含短屏。仅构建 APP，保留其他已有 dist 修改。
